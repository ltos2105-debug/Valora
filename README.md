# Valora

Projeto Integrado de Certificação em Governança e Gestão de TI / Certificação Scrum Master.

## Sobre o projeto

O Valora é um projeto baseado no desafio Bolso Firme, do GPA.

O projeto tem como objetivo auxiliar os usuários no gerenciamento de suas finanças pessoais de maneira simples e eficaz, permitindo o registro e a categorização de despesas e receitas e proporcionando uma visão mais clara dos gastos.
